# GundamDB

GundamDB is een webapplicatie voor Gunpla-verzamelaars.

Gebruikers kunnen uiteindelijk:

- Gunpla modelkits bekijken
- Modelkits zoeken en filteren
- Een persoonlijke collectie bijhouden
- Een wishlist bijhouden
- Reviews plaatsen
- Reviews van andere gebruikers bekijken

Administrators kunnen Gunpla modelkits toevoegen, wijzigen en verwijderen.

## Technieken

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- PDO
